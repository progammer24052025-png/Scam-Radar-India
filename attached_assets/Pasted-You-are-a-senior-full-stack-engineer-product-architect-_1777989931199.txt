You are a senior full-stack engineer, product architect, and UX designer with 10+ years of experience building high-trust, large-scale applications (fintech, cybersecurity, and public safety platforms).

Your task is to design and build a **production-grade web application (PWA-ready)** called:

SCAM RADAR INDIA

This is NOT a simple web app.
This is a **trust-critical system** where users rely on the platform to make real financial and safety decisions.

---

## CORE OBJECTIVE

Build a platform where users can:

* Instantly verify if a phone number, UPI ID, or message is a scam
* Understand WHY it is risky (with clear evidence)
* Report scams safely
* Receive real-time alerts about new scam patterns

The platform must feel:

* Highly trustworthy
* Official-grade
* Calm, precise, and intelligent

---

## PRIMARY DESIGN PHILOSOPHY

Do NOT design for “coolness”.

Design for:

* Trust
* Clarity
* Evidence
* Psychological safety

Every UI element must answer:
“Why should the user trust this result?”

---

Above-the-fold must include:

  “Check Before You Trust Any Payment or Message”

  * Accept:

    * Phone number
    * UPI ID
    * Message text

  * “Enter phone number…”
  * “Paste suspicious message…”

* NO login required before first use

* Subtle trust indicators:

  * “Verified reports only affect results”
  * “AI + human moderation”

---

## RESULT PAGE (MOST IMPORTANT)

Design this as the core trust interface.

SECTION 1: RISK SUMMARY

* Large numeric score (0–100)
* Label: LOW / MEDIUM / HIGH RISK
* Color-coded but controlled (not aggressive)

SECTION 2: WHY THIS RESULT

* Clear explanation in human language:

  * Example:
    “This number matches 14 verified scam reports”
    “Message contains urgency-based scam patterns”

SECTION 3: EVIDENCE PANEL

* Number of reports
* Last reported time
* Geographic distribution
* Scam category (e.g., UPI fraud, job scam)

SECTION 4: PATTERN DETECTION

* Highlight suspicious phrases in message
* Explain pattern type:

  * Urgency
  * Authority impersonation
  * Payment trap

SECTION 5: CONFIDENCE LEVEL

* Show percentage confidence (e.g., 78%)
* Never show false certainty

SECTION 6: SUGGESTED ACTION

* Clear steps:

  * Do not send money
  * Block contact
  * Report to authorities

## CORE FEATURES

1. SCAM CHECK ENGINE

* Input:

  * Phone number
  * UPI ID
  * Message text
* Output:

  * Risk score
  * Explanation
  * Evidence
  * Suggested actions

2. MESSAGE ANALYZER

* Detect:

  * Urgency phrases
  * Fake authority
  * Payment manipulation
* Highlight suspicious parts visually

3. REPORT SYSTEM

* Users submit:

  * Number / UPI / message
  * Optional screenshot
  * Description

4. VERIFICATION PIPELINE (CRITICAL)

* Reports do NOT directly affect results
* Multi-layer validation:

  * Duplicate detection
  * Pattern clustering
  * User trust score
  * Admin moderation

5. REAL-TIME ALERTS

* Notify users:

  * New scam trends
  * High-risk spikes

6. USER DASHBOARD

* Search history
* Saved alerts
* Report tracking (Under Review / Verified / Rejected)
